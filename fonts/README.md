# Montserrat Font Asset

This folder contains `Montserrat-ExtraBold.ttf` from Google Fonts, licensed under the Open Font License (OFL).

This font is used by `ffmpeg` (`libass`) in `src/video_composer.py` to burn high-contrast, bold, punchy animated subtitles centered on vertical 1080x1920 TikTok videos.
